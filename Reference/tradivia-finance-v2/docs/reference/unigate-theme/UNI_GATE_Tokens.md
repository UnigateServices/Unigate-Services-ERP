# رموز ألوان UNI GATE

المصدر المعتمد لهوية كل أنظمة UNI GATE. التنفيذ التقني: `Brand_Tokens.css` (يُنسخ كما هو إلى أي منتج).

نُسخ إلى TRADIVIA Finance v2 من نظام الصرافة في 2026-09-20 دون نسخ شاشات أو منطق الصرافة.

## ألوان الهوية (من الإدارة)

| الدور | الاسم | الكود |
|--------|--------|--------|
| أساسي | غابة | `#13362F` |
| ثانوي | رمل | `#DECFB0` |
| مساند | أردواز | `#7D9BA1` |

أحمر وكهرماني ليسا هوية؛ هما معنى (خطأ / تحذير) ويُشتقان هنا مرة واحدة لكل المنتجات.

الغابة = حبر وكروم (سايدبار، زر، شعار). الرمل = ورق ونص على الداكن. لا تُدهن الشاشة كلها بلون هوية واحد.

| الرمز | ليلي | نهاري |

| قماش الصفحة | `#0A1C18` | `#F3EBDA` |

| كروم السايدبار | `#13362F` | `#13362F` |

| نص تسميات | `#B5C4B8` | `#4F6B68` |
| زر أساسي | خلفية `#DECFB0` / نص `#13362F` | خلفية `#13362F` / نص `#DECFB0` |
| تحذير | `#C4A35A` | `#A8843A` |

متغيرات CSS العامة تبقى بأسمائها الحالية (`--primary-color`, `--bg-base`, `--danger-color`). أُضيف `--chrome-bg` و`--text-on-primary` و`--brand-forest` / `--brand-sand` / `--brand-slate`.

## قواعد الاستخدام

- لا تُعاد تعريف هذه الرموز داخل CSS المنتج.
- شاشات المنتج تبقى في ملفات ذلك النظام.
- إيصالات الطباعة الحرارية تبقى أسود/أبيض.
