# واجهات API — المرحلة الحالية

الأساس: `http://localhost:3001/api`

| الطريقة | المسار | صلاحية | الغرض |
|---------|--------|--------|--------|
| GET | `/health` | عامة | فحص الخادم |
| GET | `/auth/login-users` | عامة | أسماء الحسابات النشطة للقائمة |
| POST | `/auth/login` | عامة | دخول — يضع كوكي `tf_access` |
| POST | `/auth/logout` | عامة | إنهاء الجلسة |
| GET | `/auth/me` | مسجّل | المستخدم الحالي + مكتبه |
| GET | `/locations` | مدير عام / مشرف | المكاتب (المدير كلّها، المشرف مكتبه) |
| POST | `/locations` | مدير عام | إضافة مكتب |
| PATCH | `/locations/:id` | مدير عام | تعديل اسم/حالة |
| DELETE | `/locations/:id` | مدير عام | حذف، أو إيقاف إن كان مرتبطاً |
| GET | `/employees` | مدير عام / مشرف | قائمة المستخدمين حسب النطاق |
| POST | `/employees` | مدير عام / مشرف | إضافة حساب |
| PATCH | `/employees/:id` | مدير عام / مشرف | تعديل اسم/دور/حالة/كلمة مرور/مكتب |
| GET | `/borrowers` | مسجّل | المستلفون (الموظف يرى النشطين فقط) |
| POST | `/borrowers` | مدير عام / مشرف | إضافة مستلف |
| PATCH | `/borrowers/:id` | مدير عام / مشرف | تعديل اسم/حالة |
| DELETE | `/borrowers/:id` | مدير عام / مشرف | حذف، أو إيقاف إن كان مرتبطاً بعمليات |
| GET | `/projects` | مسجّل | المشاريع |
| POST | `/projects` | مدير عام / مشرف | إضافة مشروع |
| PATCH | `/projects/:id` | مدير عام / مشرف | تعديل اسم/حالة/أماكن الظهور |
| DELETE | `/projects/:id` | مدير عام / مشرف | حذف، أو إيقاف إن كان مرتبطاً |
| GET | `/banks` | مسجّل | البنوك |
| POST | `/banks` | مدير عام / مشرف | إضافة بنك |
| PATCH | `/banks/:id` | مدير عام / مشرف | تعديل اسم/حالة |
| DELETE | `/banks/:id` | مدير عام / مشرف | حذف، أو إيقاف إن كان مرتبطاً |
| GET | `/incomes` | مسجّل | سجل الوارد (الموظف عملياته، المشرف مكتبه، المدير الكل) |
| POST | `/incomes` | مسجّل | إنشاء وارد — الإجمالي = كمية × مبلغ على الخادم |
| DELETE | `/incomes/:id` | مدير عام / مشرف | حذف منطقي (`DELETED`) |
| GET | `/outcomes` | مسجّل | سجل الصادر (نفس نطاق الوارد) |
| POST | `/outcomes` | مسجّل | إنشاء صادر — الإجمالي = كمية × مبلغ على الخادم؛ المشروع يظهر في `OUTCOME` |
| DELETE | `/outcomes/:id` | مدير عام / مشرف | حذف منطقي (`DELETED`) |
| GET | `/exchanges` | مسجّل | سجل التصريف (نفس نطاق الوارد) |
| POST | `/exchanges` | مسجّل | إنشاء تصريف — الاتجاه والإجمالي من الخادم: شراء = ليرة→دولار، بيع = دولار→ليرة؛ السعر = ليرات لكل دولار |
| DELETE | `/exchanges/:id` | مدير عام / مشرف | حذف منطقي (`DELETED`) |
| GET | `/transfers` | مسجّل | سجل التحويل (نفس نطاق الوارد) |
| POST | `/transfers` | مسجّل | إنشاء تحويل بين صناديق؛ البنك→البنك مسموح بحسابين مختلفين؛ المستلف إلزامي عند صندوق السلف |
| DELETE | `/transfers/:id` | مدير عام / مشرف | حذف منطقي (`DELETED`) |
| GET | `/advances` | مسجّل | سجل السلف (نفس نطاق الوارد) |
| POST | `/advances` | مسجّل | إنشاء سلفة: `OUTCOME` صادر من رصيد المستلف (مشروع يظهر في `LOANS`، الإجمالي = كمية × مبلغ)، أو `EXCHANGE` تصريف داخل الرصيد (السعر والإجمالي على الخادم) |
| DELETE | `/advances/:id` | مدير عام / مشرف | حذف منطقي (`DELETED`) |
| GET | `/opening-balances` | مسجّل | سجل الرصيد الافتتاحي (نفس نطاق الوارد) |
| POST | `/opening-balances` | مدير عام / مشرف | رصيد افتتاحي لخزنة أو شام كاش موظف مختار؛ المبلغ غير صفري (يُسمح بالسالب) |
| DELETE | `/opening-balances/:id` | مدير عام / مشرف | حذف منطقي (`DELETED`) |
| GET | `/monitor` | مدير عام / مشرف | مراقبة العمليات حسب النوع والموظف وتاريخ الإدخال (افتراضي آخر 7 أيام). عرض فقط |
| GET | `/audit/requests` | مسجّل | طلبات التعديل/الحذف (الموظف طلباته، المشرف مكتبه). `status` افتراضي `PENDING` |
| POST | `/audit/requests` | موظف | طلب حذف عملية مكتملة — الحالة تصبح `PENDING_APPROVAL` |
| POST | `/audit/requests/:id/decide` | مدير عام / مشرف | موافقة أو رفض. الموافقة على الحذف تجعل العملية `DELETED`؛ الرفض يعيدها `COMPLETED`. تُحذف إشعارات الطلب المعلقة ويُنشأ إشعار قرار |
| GET | `/notifications` | مسجّل | قائمة إشعارات المستخدم الحالي. `section` = `pending` (افتراضي) أو `approved` أو `rejected`. المعلقة تظهر فقط إن كان الطلب لا يزال معلّقاً |
| GET | `/notifications/counts` | مسجّل | عدّاد الإشعارات حسب القسم — شارة الواجهة = `pending` |
| DELETE | `/notifications/:id` | مسجّل | حذف إشعار غير معلّق يخص المستخدم. المعلقة تُرفض (`NOTIF_PENDING_KEEP`) |
| GET | `/reports/catalog` | مسجّل | كتالوج التقارير حسب الدور (موظف / مشرف / مدير) |
| POST | `/reports/run` | مسجّل | تشغيل تقرير: مؤشرات + رسوم + جداول. النطاق نفس العمليات. الفترة حسب تاريخ العملية. التحويل الداخلي لا يُحتسب دخلاً |
| GET | `/balances` | مسجّل | أرصدة الصناديق محسوبة (موظف: عملياته، مشرف: مكتبه، مدير: الكل) — خزنة، شام كاش، بنوك، سلف |
| GET | `/warehouses` | مسجّل | المستودعات. يُنشأ «المستودع الرئيسي» إن لم يوجد |
| POST | `/warehouses` | مدير عام | مستودع إضافي |
| PATCH | `/warehouses/:id` | مدير عام | اسم / حالة / جعله الافتراضي |
| GET | `/products` | مسجّل | كتالوج الصنف مع الرصيد في المستودع المختار |
| POST | `/products` | مدير عام / مشرف | صنف جديد. الرمز يُولَّد إن تُرك فارغاً |
| PATCH | `/products/:id` | مدير عام / مشرف | تعديل الصنف |
| DELETE | `/products/:id` | مدير عام / مشرف | حذف إن بلا حركات، وإلا إيقاف |
| POST | `/products/:id/image` | مدير عام / مشرف | صورة الصنف (حقل `file`) |
| GET | `/products/:id/image` | مسجّل | عرض الصورة |
| DELETE | `/products/:id/image` | مدير عام / مشرف | إزالة الصورة |
| GET | `/stock-movements` | مسجّل | آخر حركات المستودع |
| POST | `/stock-movements` | موظف فأعلى | إدخال / إخراج / جرد. الرصيد لا يصبح سالباً. الجرد للمدير والمشرف |
| GET | `/customers` | مسجّل | الزبائن. الموظف والمراقب يريان النشطين فقط |
| POST | `/customers` | مدير عام / مشرف | زبون جديد |
| PATCH | `/customers/:id` | مدير عام / مشرف | تعديل الزبون |
| DELETE | `/customers/:id` | مدير عام / مشرف | حذف، أو إيقاف إن رُبط بفاتورة |
| GET | `/sales-invoices` | مسجّل | فواتير البيع ضمن نطاق العمليات |
| GET | `/sales-invoices/:id` | مسجّل | فاتورة مع البنود والقبض |
| POST | `/sales-invoices` | موظف فأعلى | مسودة. الإجمالي والحسم على الخادم |
| PATCH | `/sales-invoices/:id` | موظف فأعلى | تعديل مسودة ضمن النطاق |
| DELETE | `/sales-invoices/:id` | موظف فأعلى | حذف مسودة |
| POST | `/sales-invoices/:id/post` | موظف فأعلى | ترحيل: إخراج مخزون في معاملة واحدة. الرصيد لا يصبح سالباً |
| POST | `/sales-invoices/:id/void` | مدير عام / مشرف | إلغاء مع سبب بعد عكس كل قبض قائم، وإعادة الكمية للمستودع |
| POST | `/sales-invoices/:id/payments` | موظف فأعلى | قبض يُنشئ وارداً. لا يتجاوز المتبقي |
| POST | `/sales-invoices/:id/payments/:paymentId/reverse` | مدير عام / مشرف | عكس القبض وحذف الوارد منطقياً |
| GET | `/suppliers` | مسجّل | الموردون. الموظف والمراقب يريان النشطين فقط |
| POST | `/suppliers` | مدير عام / مشرف | مورد جديد |
| PATCH | `/suppliers/:id` | مدير عام / مشرف | تعديل المورد |
| DELETE | `/suppliers/:id` | مدير عام / مشرف | حذف، أو إيقاف إن رُبط بفاتورة |
| GET | `/purchase-invoices` | مسجّل | فواتير الشراء ضمن نطاق العمليات |
| GET | `/purchase-invoices/:id` | مسجّل | فاتورة مع البنود والدفع |
| POST | `/purchase-invoices` | موظف فأعلى | مسودة شراء |
| PATCH | `/purchase-invoices/:id` | موظف فأعلى | تعديل مسودة |
| DELETE | `/purchase-invoices/:id` | موظف فأعلى | حذف مسودة |
| POST | `/purchase-invoices/:id/post` | موظف فأعلى | ترحيل: إدخال مخزون وتحديث متوسط التكلفة |
| POST | `/purchase-invoices/:id/void` | مدير عام / مشرف | إلغاء بعد عكس الدفع، وإخراج الكمية إن توفّر الرصيد |
| POST | `/purchase-invoices/:id/payments` | موظف فأعلى | دفع يُنشئ صادراً ولا يتجاوز المتبقي |
| POST | `/purchase-invoices/:id/payments/:paymentId/reverse` | مدير عام / مشرف | عكس الدفع وحذف الصادر منطقياً |

رموز فشل الدخول (كما في GAS): `WRONG_CREDENTIALS`، `INACTIVE`.

قواعد الإنشاء: المشرف يضيف موظفين في مكتبه فقط. المدير العام يضيف أي دور ويحدد المكتب للمشرف والموظف.

المستلفون والمشاريع والبنوك **ليست قوائم ثابتة في الكود** — تُدار من الواجهة. الحذف الفعلي يتم إن لم تُستخدم السجلات في عمليات؛ وإلا تُوقف (`INACTIVE`) حتى تبقى القيود التاريخية.
