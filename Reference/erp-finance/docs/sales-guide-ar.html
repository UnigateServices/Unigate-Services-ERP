٣. شاشة فواتير المبيعات (القائمة)

بطاقات الأعلى

  • فواتير ضمن العرض — بعد البحث والفلتر.
  • مسودات — عدد المسودات الظاهرة.
  • مرحّلة غير مسدّدة — مرحّلة ولم تُقفل بالقبض الكامل.
  • الذمة المفتوحة · USD/SYP — مجموع المتبقي على الفواتير المرحّلة لكل عملة.

أدوات

  • بحث بالرقم أو الزبون — فلتر: الكل | مسودة | مرحّلة | ملغاة.
  • + فاتورة جديدة — الذمم والتحصيل (يفتح المحاسبة) — تصدير CSV — الأعمدة لإظهار/إخفاء أعمدة.

النقر على صف يفتح الفاتورة. زر قبض دفعة في الصف للمرحّلة غير المسدّدة بالكامل.

٤. إنشاء وتعديل فاتورة (مسودة)

الحقلالشرح
الزبونبحث؛ تلميح: هاتف، مدينة، ضريبي، مهلة دفع. إنشاء سريع (اسم + هاتف) للمدير/المشرف.
التاريخ / الاستحقاقالاستحقاق = التاريخ + مهلة دفع الزبون (قابل للتعديل). مهلة 0 = نفس يوم الفاتورة.
العملةUSD أو SYP. بعد الترحيل يظهر سعر الصرف إن وُجد.
المكتبللمدير العام فقط؛ لغيره ثابت.
المستودعيحدد الأصناف والرصيد تحت كل بند.
المندوبمنشئ الفاتورة (قراءة فقط).
المرجع / ملاحظاتمرجع خارجي اختياري؛ ملاحظات حرة.

البنود

الصنف (بحث/باركود، رصيد تحت الصنف)، الوصف، الكمية، السعر الإفرادي (من سعر البيع)، خصم (مبلغ أو %)، الإجمالي. + بند جديد، مسح باركود.

اختصارات: Enter بين الحقول؛ Ctrl+S حفظ مسودة؛ Ctrl+Enter ترحيل (مع تأكيد).

الإجماليات: المجموع، خصم الفاتورة (مبلغ/%)، الصافي.

الأزرار: حفظ مسودة | اعتماد وترحيل | ⋯ حذف المسودة (بعد الحفظ).

الأثر المحاسبي (يسار الصفحة)

قبل الترحيل: معاينة (ذمة الزبون ترتفع بالصافي؛ المخزون ينقص). بعد الترحيل: قيد فعلي (حسابات مدين/دائن، متوازن). عند الترحيل يُنشأ أيضاً بند ذمة في نظام الذمم.

٥. فاتورة بعد الترحيل

  • حقول وبنود مقفلة.
  • طباعة — تسجيل قبض إن المتبقي > 0.
  • ⋯ → إلغاء الفاتورة (مدير/مشرف + سبب).
  • الدفعات والتسويات: قائمة القبض (تاريخ، مبلغ، مرجع الوارد، قائم/ملغى)؛ عكس القبض للمدير/المشرف.

٦. نافذة قبض دفعة

يعرض المتبقي. يُنشأ وارد مكتمل بنفس المبلغ.

المشروعمشاريع مفعّل لها «وارد» فقط

٧. شاشة الزبائن

قائمة: الاسم، الهاتف، المدينة، الرقم الضريبي، مهلة الدفع، الحالة. بحث بالاسم أو الهاتف.

ملف الزبون (لوحة جانبية)

  • البيانات الأساسية: الاسم، هاتف، بريد، مدينة، عنوان، ضريبي، نشط/موقوف، ملاحظات.
  • الائتمان: الذمة المفتوحة لكل عملة، عدد فواتير مرحّلة، مهلة الدفع بالأيام.
  • كشف الفواتير: رقم، تاريخ، إجمالي، مدفوع، متبقي، حالة — تصدير CSV — فاتورة جديدة — حذف أو إيقاف (إن له فواتير → إيقاف فقط).

٨. وصول سريع من الشريط العلوي

  • جديد → فاتورة مبيعات أو سند قبض.
  • بحث: اكتب SI أو اسم زبون → فتح فاتورة أو سند قبض.

١٠. دورة العمل الموصى بها (المبيعات)

  1. زبون (+ مهلة دفع إن لزم).
  2. أصناف في المخزون برصيد وسعر بيع.
  3. فاتورة مسودة → حفظ → اعتماد وترحيل.
  4. قبض دفعة (مشروع + صندوق).
  5. للتصحيح: عكس القبض ثم إلغاء الفاتورة إن لزم (مع سبب).

١٢. الصلاحيات (المشتريات)

نفس منطق المبيعات: المدير العام والمشرف يديران الموردين ويلغيان الفواتير؛ الموظف ينشئ ويرحّل مسوداته ويدفع؛ المراقب عرض فقط + الذمم والتحصيل. رؤية الفواتير: مدير/مراقب كل المكاتب، مشرف مكتبه، موظف فواتيره فقط (حتى 200 فاتورة).

١٣. شاشة فواتير المشتريات (القائمة)

بطاقات الأعلى

  • فواتير ضمن العرض، مسودات، مرحّلة غير مسدّدة.
  • المستحق للموردين · USD/SYP — مجموع المتبقي على فواتير الشراء المرحّلة.

أدوات

  • بحث بالرقم أو المورد — فلتر الحالة — + فاتورة جديدة — الذمم والتحصيل — تصدير CSV — الأعمدة.

أعمدة الجدول: الرقم، التاريخ، المورد، المستودع، الإجمالي، المتبقي، الحالة، الموظف. زر تسجيل دفعة للمرحّلة غير المسدّدة بالكامل.

البنود

الإجماليات: المجموع، خصم الفاتورة (مبلغ فقط)، الصافي.

الأثر المحاسبي (معاينة قبل الترحيل)

  • ذمة المورد ترتفع بمقدار الصافي.
  • المخزون يزيد بكميات البنود (إدخال مخزني).

بعد الترحيل: قيد فعلي (مدين مخزون أو مصروف حسب سياسة الجرد الدوري/المستمر)، دائن ذمم موردين، وبند ذمة مورد في نظام الذمم.

١٥. فاتورة شراء بعد الترحيل

  • طباعة — تسجيل دفعة إن المتبقي > 0.
  • ⋯ → إلغاء الفاتورة (مدير/مشرف + سبب). يتطلب عدم وجود دفعات قائمة، وعند الإلغاء يُخرج المخزون (يجب أن تكون الكميات ما زالت متوفرة).
  • الدفعات والتسويات: سندات الصادر المرتبطة؛ عكس الدفع للمدير/المشرف.

٢٠. دورة العمل (المشتريات)

  1. مورد نشط.
  2. أصناف في المخزون (يمكن إنشاء صنف من الفاتورة).
  3. فاتورة شراء مسودة → اختيار مستودع وبنود بتكلفة → (اختياري) دفعة للمورد → ترحيل.
  4. تسجيل دفعة للمورد (مشروع صادر + صندوق).
  5. للتصحيح: عكس الدفع ثم إلغاء الفاتورة إن لزم.

٢٢. شاشة المستودع — تبويب الأصناف

بطاقات الأعلى

  • عدد الأصناف في المستودع المختار.
  • قيمة المخزون — مجموع (الرصيد × متوسط التكلفة).
  • أصناف تحت الحد — تنبيه عند > 0.
  • حركات اليوم — عدد حركات المخزون اليوم.

أدوات وفلاتر

  • تبويبان: الأصناف | سجل الحركات.
  • فلاتر مع العدد: الكل، متوفر، تحت الحد، نفد، موقوف.
  • قائمة المستودع (كل الأرصدة تخص المستودع المختار).
  • بحث بالاسم أو الباركود — Enter على باركود يفتح الصنف مباشرة.
  • + صنف جديد — تقييم المخزون — المستودعات (للمدير العام فقط) — الأعمدة.

إن كان المستودع موقوفاً تظهر رسالة: الأرصدة للعرض فقط ولا تُقبل حركات جديدة.

أعمدة جدول الأصناف

الباركود، اسم المادة، الرمز (SKU)، المستودع، الرصيد المتوفر، الوحدة، متوسط التكلفة، إجمالي القيمة، الحالة. زر حركة للصنف النشط في مستودع نشط (حسب صلاحية الحركة).

٢٣. نافذة الصنف

  • صورة: رفع/سحب وإفلات (لمن يملك صلاحية الإدارة).
  • الرصيد في المستودع الحالي + الحالة + حد إعادة الطلب + زر تسجيل حركة.
  • الحقول: الاسم، الرمز (يُولَّد تلقائياً إن تُرك فارغاً)، الباركود، الوحدة، الحالة، تكلفة الوحدة، سعر البيع، حد إعادة الطلب، ملاحظات (تظهر كوصف افتراضي في الفواتير).
  • آخر الحركات في هذا المستودع (حتى 6).
  • إيقاف أو حذف: حذف نهائي إن لا حركات؛ وإلا إيقاف فقط.

من دون صلاحية إدارة: عرض البيانات والرصيد فقط.

٢٤. نافذة تسجيل حركة

يُشترط أن يكون للصنف تكلفة أكبر من صفر. تظهر معاينة «الرصيد بعد الحركة». ملاحظة في الشاشة: الحركة تُرحَّل إلى حساب المخزون بالتكلفة الحالية؛ الزيادة فائض والنقص عجز.

٢٥. تبويب سجل الحركات

مؤشرات: الحركات المعروضة، عدد إدخال، إخراج، جرد. فلتر النوع وبحث بالمرجع أو الصنف.

الأعمدة: المرجع، الصنف، نوع الحركة، الكمية (+/−)، الموظف، ملاحظات، الوقت. يشمل حركات الفواتير المرحّلة والحركات اليدوية. النقر يفتح ملف الصنف.

٢٦. تقييم المخزون

صفحة تقرير (طباعة): المستودع، التاريخ، عدد الأصناف، جدول (صنف، كمية، متوسط التكلفة، القيمة)، إجمالي قيمة المخزون. للقراءة لا يغيّر الأرصدة.

٢٧. إدارة المستودعات (المدير العام)

  • إضافة مستودع بالاسم.
  • تعديل الاسم — تعيين كافتراضي — إيقاف/تفعيل.
  • لا يمكن إيقاف المستودع الافتراضي النشط.

٢٨. شاشة صافي القيمة

تقارن تكلفة كل صنف بما يمكن بيعه به اليوم. إن البيع أقل من التكلفة يُسجَّل هبوط (مصروف) حتى لا يُقيَّم المخزون بأكثر من قيمته الحقيقية.

مؤشرات

  • عدد الأصناف ذات الكمية.
  • قيمة بالتكلفة.
  • هبوط هذا القياس (يُرحَّل عند الحفظ).
  • عكس خسارة سابقة (في حدود التكلفة).

الجدول والإجراء

لكل صنف: الكمية، التكلفة، سعر البيع الحالي، حقل يُباع الآن (ما يمكن بيع الوحدة به فعلياً — الصفر مسموح)، النتيجة (يغطي التكلفة / هبوط X)، خسارة سابقة مسجّلة.

رأس القياس: تاريخ القياس، عملة القياس، ملاحظة. زر ترحيل القياس ينشئ قيداً محاسبياً.

إن لم توجد كميات: «لا يوجد مخزون لقياسه» — أضف كمية من المستودع أولاً.

٢٩. صلاحيات المخزون (ملخص)

الصلاحيات الفعلية (إدارة أصناف، تسجيل حركة، جرد) تُحدَّد من الخادم حسب الدور وقد تظهر في الشاشة كأزرار مخفية. بشكل عام: المدير والمشرف يديران الأصناف والمستودعات؛ الحركة والجرد للمخوّلين؛ المراقب يعرض بما فيه صافي القيمة.

٣٠. ربط المخزون بالمبيعات والمشتريات

  • ترحيل فاتورة شراء: إدخال مخزني + تحديث متوسط التكلفة (في الجرد المستمر).
  • ترحيل فاتورة بيع: إخراج مخزني؛ يُرفض الترحيل إن الرصيد غير كافٍ.
  • إلغاء فاتورة بيع: إعادة الكميات للمخزون.
  • إلغاء فاتورة شراء: إخراج الكميات من المخزون (يتطلب رصيداً كافياً).
  • الفواتير والحركات اليدوية كلها تظهر في سجل الحركات.

٣١. دورة العمل (المخزون)

  1. تعريف المستودعات (مدير) واختيار الافتراضي.
  2. إنشاء أصناف: تكلفة، سعر بيع، حد إعادة الطلب، باركود إن وُجد.
  3. إدخال كميات: فاتورة شراء مرحّلة، أو حركة إدخال يدوية.
  4. متابعة الفلاتر (تحت الحد / نفد) وتقييم المخزون للتقارير.
  5. جرد دوري بحركة جرد؛ قياس صافي القيمة عند الحاجة المحاسبية.
